# Khatib — 3D direction test

Five-second, 1920×1080, 24 fps look-development sample for the premium product-launch direction. This is a sample, not the full promotional film.

Native Blender geometry, PBR materials, animated tiles, perspective camera, depth of field, motion blur and compositor glow. No image generation or HTML rendering. The floating board is an abstract representation of the engine's calculation; this sample does not depict a recorded game or make performance claims.

Open `Khatib-3D-Test.blend` in Blender 5.2. The scene contains the editable geometry, lighting and animation. `build.py` recreates it. The exported MP4 adds the music and sound effect separately using FFmpeg.
