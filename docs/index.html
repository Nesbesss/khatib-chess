1.0

A chess engine written from an empty directory, in one sitting.

Bitboard move generation, alpha-beta search, and a neural network evaluation trained on 30 million positions labelled by Stockfish. Rust, no dependencies. Every number below was measured by playing games — on this project the convenient proxies were wrong more often than right.

Thirty hard positions, one second each, all three engines on the same machine. Khatib scores 11–12 across runs, so the gap to Stockfish is small but real.

How it works

Move generation
Magic bitboards, fully legal — pins and checks resolved before a move is emitted, so nothing needs verifying afterwards.
Search
Iterative deepening with aspiration windows, a transposition table, quiescence with static exchange evaluation, null-move pruning and late move reductions.
Evaluation
NNUE, 768×4 king buckets → 1024×2 → 1. Incrementally updated: a move changes two feature columns rather than the whole layer.
Threading
Lazy SMP over a lock-free table. Entries verify as key ⊕ data, so a torn read is discarded rather than trusted.
Opening book
109 positions of mainline theory, answered instantly instead of spending the clock rediscovering them.
In the browser
The whole engine compiles to 90 KB of WebAssembly, so the play site runs it client-side with no server.

Four bugs the tests missed

The move generator passed all thirty-three standard perft positions, including cases counting 178 and 193 million nodes.

Capturing a king
A pawn, knight or slider attacking the enemy king's square generated a capture of the king, removing it from the board — every later lookup then indexed past the attack tables and crashed. No standard perft position lets a piece reach a king square.
Identical shards
Every parallel worker seeded from its own index, so 12 million generated positions deduplicated to 79,699. A later variant made each whole run reproduce the previous one.
Silent truncation
An interrupted upload left a partial file and training ran to completion on 0.7% of the data without complaint.
A referee that never called a result
The match runner scored every game a draw because it never detected checkmate, so an entire class of measurement was noise until it was caught.

Running it

cargo build --release

./target/release/chess              UCI mode, for any chess GUI
./target/release/chess serve        board and live search view
./target/release/chess perft 6      move generator verification
./target/release/chess match 100    measure a network in games

Speaks standard UCI, so it drops into any chess interface. 21 unit tests and a perft suite; the deep cases run with cargo test --release -- --ignored.
